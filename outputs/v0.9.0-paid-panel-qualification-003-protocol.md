# v0.9.0 paid panel qualification 003 protocol

## status

Frozen before provider calls. Do not edit this protocol after execution.

## purpose

Qualification `003` verifies the four production adapters after the v0.9.0 continuation, public-record, prompt, checkpoint, and CLI changes. It is a technical compatibility check. It contains no survivor name, energy, peer, action, scarcity, memory, or survival context.

The probe is unchanged from qualification `002`.

System text:

```text
You are performing an API compatibility check, not a game or decision task.
Return exactly one JSON object and nothing else. Do not explain your answer.
```

User text:

```text
Return an object with exactly these keys and literal values:
{"protocol":"world-sim-adapter-v1","ok":true}
```

Whitespace and key order can vary. Duplicate keys, Markdown, trailing text, additional keys, different values, invalid JSON constants, and responses over 8,192 UTF-8 bytes fail.

## pass and stopping rules

A model must return HTTP 200, terminal completion, final text, strict JSON, and the exact fixed object. It must also return valid usage and cost data, exact model identity, and a cost within its request bound.

The panel passes only at 4/4. The runner makes no retry or repair call. It continues after a model-local failure while authorization remains. A cost-bound breach can prevent later transport; the retained artifact must identify those unattempted models.

Preserve the artifact whether the panel passes or fails. Do not run session 2 unless qualification `003` passes 4/4.

## cost gate

The 20,000-input-token and 10,000-output-token envelope is:

| model | conservative bound |
| --- | ---: |
| DeepSeek V4 Flash | `$0.00700` |
| Grok 4.5 | `$0.12500` |
| Kimi K2.6 | `$0.07375` |
| GLM 5.2 | `$0.09000` |

The total is `$0.29575` after the 1.25 safety factor. The command authorizes `$0.30` and prices each exact request before transport.

This is a local request gate, not a card-charge guarantee. A timeout can be billed. OpenCode prices and account auto-reload are outside this process.

## run

The output path must not exist. Put the authorized key on the clipboard, then run:

```powershell
$env:PYTHONPATH = "src"
$env:OPENCODE_ZEN_API_KEY = (Get-Clipboard -Raw).Trim()
try {
  py -3.11 -m world_sim qualify-live `
    --model opencode-paid/deepseek-v4-flash `
    --model opencode-paid/grok-4.5 `
    --model opencode-paid/kimi-k2.6 `
    --model opencode-paid/glm-5.2 `
    --max-completion-tokens 10000 `
    --temperature 0.2 `
    --max-paid-usd 0.30 `
    --timeout-seconds 300 `
    --output outputs\v0.9.0-paid-panel-qualification-003.json
  if ($LASTEXITCODE -ne 0) {
    throw "paid adapter qualification failed; preserve the artifact and do not retry"
  }
} finally {
  Remove-Item Env:OPENCODE_ZEN_API_KEY -ErrorAction SilentlyContinue
  Remove-Item Env:PYTHONPATH -ErrorAction SilentlyContinue
}
```
