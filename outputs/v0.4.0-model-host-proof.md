# v0.4.0 model-host proof

## claim

For successful replies, the live host makes one tool-free request per living seat and day, excludes credentials from artifacts, preserves failures, and creates a result replayable without model calls.

## result

Environment: Windows, Python 3.11, 2026-08-12.

```powershell
$env:PYTHONPATH = "src"
py -3.11 -m unittest discover -s tests -v
```

Result: 51 tests passed. The focused host tests cover the exact request surface, two seats over three days, no-call replay, call-cap preflight, and credential isolation. They also cover malformed model JSON, completion-budget exhaustion, and sanitized transport, HTTP, and provider-envelope failures.

A real request to `opencode/mimo-v2.5-free` established why the completion cap cannot equal the short visible-answer size. With a 512-token cap, the provider reported 511 reasoning tokens, `finish_reason: length`, and no final content. The local receipt is `artifacts\live-smoke-17.json`. The adapter now permits at most 4,096 completion tokens and retains provider-reported reasoning usage.

The final two-model smoke attempt did not complete. OpenCode returned HTTP 429 on the first call, before day 1 changed world state. `artifacts\live-smoke-reasoning-17.json` reported `days_completed: 0`, `calls_attempted: 1`, and `calls_failed: 1`. The authenticated free route returned the same quota error, while the configured OpenCode Go account reported insufficient balance.

## bound

The passing suite proves the host and engine boundary with fake provider responses. The real request proves endpoint reachability and the reasoning-budget behavior observed for MiMo on this date. It does not prove a complete live world run or any claim about model cooperation, strategy, or survival. OpenCode model availability and free quota are external, changing conditions.
