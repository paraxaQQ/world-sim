# v0.12.1 GPT-5.6 Luna qualification 005 protocol

## status

Frozen before provider calls. Qualification 005 may execute once. Its output is retained whether it passes or fails.

## purpose

This is a nonbehavioral adapter probe. It asks GPT-5.6 Luna for one fixed JSON object through the exact Responses API path that a survival turn will use. It contains no survivor identity, energy, inventory, peers, scarcity, choices, or campaign history.

Qualification 004 returned HTTP 400. Its sanitized receipt does not contain enough provider error detail to prove the exact cause. Qualification 005 tests the repaired wire contract without rerunning any survival behavior.

## fixed request

| setting | value |
| --- | --- |
| model | `opencode-paid/gpt-5.6-luna` |
| endpoint | `https://opencode.ai/zen/v1/responses` |
| expected object | `{"protocol":"world-sim-adapter-v1","ok":true}` |
| maximum completion tokens | `4096` |
| reasoning effort | `low` |
| timeout | `300` seconds |
| calls | `1` |
| retries or repair calls | `0` |
| maximum local authorization | `$0.03` |

The strict response schema uses explicit types and single-value enums. For Luna only, the same request builder converts the survival action union from `oneOf` to the documented `anyOf` subset and converts each literal `const` to an equivalent typed single-value enum. The world prompt, local parser, physical rules, other provider requests, and committed historical artifacts remain unchanged.

## pass rule

The probe passes only if all of these are true:

1. OpenCode returns HTTP 200 and terminal completion.
2. The provider reports the requested model identity.
3. The final text is strict JSON with exactly the two expected keys and values.
4. Usage and provider cost are present and internally consistent.
5. The accounted cost remains inside the preauthorized request bound.

Any failure is final for qualification 005 and blocks Session 4.

## frozen command

The output path must not already exist.

```powershell
$env:PYTHONPATH = "src"
$env:OPENCODE_ZEN_API_KEY = (Get-Clipboard -Raw).Trim()
try {
  py -3.11 -m world_sim qualify-live `
    --model opencode-paid/gpt-5.6-luna `
    --max-completion-tokens 4096 `
    --reasoning-effort low `
    --max-paid-usd 0.03 `
    --timeout-seconds 300 `
    --output outputs\v0.12.1-gpt-5.6-luna-qualification.json
} finally {
  Remove-Item Env:OPENCODE_ZEN_API_KEY -ErrorAction SilentlyContinue
  Remove-Item Env:PYTHONPATH -ErrorAction SilentlyContinue
}
```

## behavioral gate

Do not run Session 4 unless qualification 005 passes. A pass establishes adapter compatibility only. It does not measure Luna's judgment, cooperation, deception, survival strategy, or social behavior.
