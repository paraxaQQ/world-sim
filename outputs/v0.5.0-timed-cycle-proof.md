# v0.5.0 timed-cycle proof

## claim

The survival engine supports deterministic four-chance interaction cycles, exact offline replay, audience-safe observations, and a hard per-request live-call limit. The `lean-camp-v1` scripted ecology passes all 21 fixed balance gates on held-out seeds.

## result

The focused gates covered:

- next-chance speech and replies

- malformed actions wasting a chance instead of counting as rest
- static slot-input failures leaving the world unchanged
- fake paid transport making exactly four authorized calls and blocking the fifth before transport
- the GLM request using JSON-object mode with the exact model-facing response schema in its prompt

## bound

This proves engine behavior, replay, privacy boundaries, host call limiting, and the scripted ecology's balance properties. It shows that one fixed visible-information risk-pooling policy improves survival in this world. It does not show how any live model behaves in the multi-chance world. It does not establish model cooperation, alliances, deception, morality, or a paper-worthy effect. Combat, theft, reproduction, money, tools, and self-modification remain absent.
