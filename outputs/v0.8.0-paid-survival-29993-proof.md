## receipt caveat

The frozen protocol said the survival CLI would checkpoint before and after each call. The implementation reserved the output path before transport but wrote the full artifact only after the episode returned. The completed artifact, source-hash match, and exact replay are intact. An interruption would not have retained the promised partial trace. v0.8.1 fixes this receipt path for future episodes; this run was not repeated.

Provider-reported cost is an API receipt, not proof of the final card charge. Zen account auto-reload remains outside the local gate.
