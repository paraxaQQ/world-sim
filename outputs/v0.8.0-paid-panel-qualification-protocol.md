# v0.8.0 paid panel qualification protocol

## status

Frozen before provider calls. Qualification `001` executed once on 2026-08-13 and failed at 3/4. It was not retried.

## purpose

This is an adapter qualification, not a survival episode. It tests whether each planned paid model can complete the exact production request path and return strict JSON within the configured cost bound.

The probe contains no survivor name, energy, peers, world state, allowed actions, scarcity, or survival framing. It cannot measure cooperation, competition, reasoning quality, concise decision-making, or social behavior. It consumes no behavioral seed.

## fixed probe

System text:

```text
You are performing an API compatibility check, not a game or decision task.
Return exactly one JSON object and nothing else. Do not explain your answer.
```

User text:

```text
Return an object with exactly these keys and literal values:
{"protocol":"world-sim-adapter-v1","ok":true}
```

Whitespace and key order can vary. The response fails if it contains duplicate keys, Markdown, trailing text, additional keys, different values, an invalid JSON constant, or more than 8,192 UTF-8 bytes.

## request controls

| setting | value |
| --- | --- |
| calls per model | `1` |
| total calls | `4` |
| maximum completion tokens | `10000` |
| reasoning profile | `provider-default` |
| temperature | `0.2` |
| timeout per request | `300` seconds |
| retries | `0` |
| repair calls | `0` |
| maximum local authorization | `$0.30` |
| maximum input-token bound per request | `20000` |

Provider-default reasoning sends no reasoning-effort override. The provider-specific request builder, endpoint, JSON mode, envelope parser, usage parser, cost parser, and output cap are the same ones used by `survive-live`.

## pass rule

A model passes only if all of these conditions hold:

1. The provider accepts the request and returns HTTP 200.
2. The provider reports terminal completion instead of a length or incomplete stop.
3. The normalized envelope contains final text.
4. The text is valid strict JSON and matches the fixed object exactly.
5. The response contains valid usage and paid-cost data.
6. The requested and provider-reported model identities match.
7. The accounted cost does not exceed the preauthorized request bound.

The panel passes only if all four models pass. The runner continues after a model-local failure so one bad adapter does not hide the status of later models. If a failure has no trustworthy cost receipt, its full request bound remains reserved before the next call. Cost safety overrides continuation: if a provider exceeds its authorized request bound, later calls that no longer fit under `$0.30` receive retained `paid_budget_exhausted` records and are not transported.

The CLI atomically checkpoints a complete running artifact before every transport and after every result. An interruption can leave an `in_flight` record, but it cannot reduce the output to an unexplained reservation after a call was authorized.

Reasoning-token detail is recorded when available but is not required.

## cost gate

At the pinned OpenCode Zen prices, a 20,000-input-token and 10,000-output-token envelope produces these conservative per-call bounds after the host's 1.25 safety factor:

| model | conservative bound |
| --- | ---: |
| DeepSeek V4 Flash | `$0.00700` |
| Grok 4.6 | `$0.12500` |
| Kimi K2.6 | `$0.07375` |
| GLM 5.2 | `$0.09000` |

The four-call envelope totals `$0.29575`, so this protocol authorizes `$0.30`. The host also prices each exact request and records both the request bound and cumulative exposure before transport. It accepts either a dollar cost or Responses API `usage.cost_in_usd_ticks`, converts ticks at 10 billion per US dollar, and rejects conflicting values.

This is a local request gate, not a card-charge guarantee. A timeout can be billed, provider prices can change, and OpenCode Zen account auto-reload is outside this process. Disable auto-reload or set an account-level limit if card-level control is required.

## run

The output path must not exist. Put the authorized key on the clipboard, then run:

```powershell
$env:PYTHONPATH = "src"
$env:OPENCODE_ZEN_API_KEY = (Get-Clipboard -Raw).Trim()
try {
  py -3.11 -m world_sim qualify-live `
    --model opencode-paid/deepseek-v4-flash `
    --model opencode-paid/grok-4.6 `
    --model opencode-paid/kimi-k2.6 `
    --model opencode-paid/glm-5.2 `
    --max-completion-tokens 10000 `
    --temperature 0.2 `
    --max-paid-usd 0.30 `
    --timeout-seconds 300 `
    --output outputs\v0.8.0-paid-panel-qualification-001.json
} finally {
  Remove-Item Env:OPENCODE_ZEN_API_KEY -ErrorAction SilentlyContinue
  Remove-Item Env:PYTHONPATH -ErrorAction SilentlyContinue
}
```

Do not retry an individual provider call. Preserve a failed artifact. An adapter change can be re-qualified because this probe elicits no experiment behavior, but it must use a new output name and retain the earlier artifact.

The same authenticated Zen model-list endpoint advertised Grok 4.6, and the current Zen documentation listed it on the Responses endpoint. The retained error body is limited to its HTTP status, byte count, hash, and request ID, so this result cannot identify why the provider denied inference.
