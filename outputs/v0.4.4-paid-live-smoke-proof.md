## objective correction

GLM returned a valid JSON envelope but encoded its action as the string `"gather_wood"` instead of the required object `{"kind":"gather_wood"}`. Its speech said it was gathering wood. The protocol recorded `action must be an object`, replaced only the invalid action with the paid `rest` fallback, and retained the valid message.

This is useful boundary evidence: model narration did not alter world state. It is one formatting failure in one smoke run, not evidence of deception or a stable model trait.

## request audit

Every recorded request used `thinking: {"type":"disabled"}` and omitted `reasoning_effort`. DeepSeek, Kimi, and GLM requested JSON-object responses. MiniMax used its narrower compatible request without `response_format` or `temperature`. No request included tools.
